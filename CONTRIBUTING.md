# Contributing

Спасибо, что хотите помочь **Nereus**! Мы — небольшой открытый проект, и каждый
вклад важен. Вот краткая инструкция, с которой стоит начать.

## Как найти задачу

- Открытые задачи — в [issues](https://github.com/nereuslabs/Nereus/issues).
- Приоритет и статус — на [доске проекта](https://github.com/orgs/nereuslabs/projects/1).
- Для первого вклада ищите метки `good first issue` или `help wanted`.
- Если задача неочевидна — напишите комментарий в issue до начала работы,
  чтобы не сделать лишнего.

## Процесс

Мы используем **GitHub Flow** с интеграционной веткой `develop`:

1. Форкните репозиторий и создайте ветку от `develop`:
   `git checkout -b feature/issue-<N>-short-name`
2. Внесите изменения и запустите проверки локально (см. ниже).
3. Запушьте ветку и откройте Pull Request **на `develop`**.
4. В описании PR укажите `Fixes #N` — так задача закроется автоматически.
5. Дождитесь зелёного CI (`ruff check` + `ruff format --check` + `pytest`) и ревью.
   `develop` требует строгий линейный исторический порядок (squash/merge); `main`
   дополнительно требует 1 одобряющего review — выпускайте релисы через `main`.

## Локальная разработка

Требуется **Python 3.11+**:

```bash
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"

# линтер, проверка формата и тесты (должны быть зелёными до PR)
ruff check .
ruff format --check .
pytest
```

## Правила

- Комментарии в коде — на английском, описания issues/PR — на русском.
- Не увеличивайте покрытие кода без теста: для новой логики добавляйте тест.
- Не закоммичивайте секреты (`.env`, ключи) — они в `.gitignore`.
- Держите изменения маленькими и сфокусированными: один PR — одна задача.

## Вопросы

Задача занята или что-то непонятно? Оставьте комментарий в issue — мы на связи.

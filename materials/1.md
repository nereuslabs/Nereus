# Python fundamentals

## Variables and types

Python is dynamically typed. Common built-in types:

- `int`, `float`, `bool` — numbers
- `str` — text
- `list`, `tuple`, `dict`, `set` — collections

```python
age: int = 30
name: str = "Nereus"
scores: list[float] = [9.5, 8.0, 10.0]
```

Type hints (`int`, `str`, `list[float]`) are optional but recommended for
readability and tooling. They are **not** enforced at runtime.

## Control flow

```python
if age >= 18:
    print("adult")
elif age > 13:
    print("teen")
else:
    print("child")

for item in scores:
    print(item)

while age < 100:
    age += 1
```

## Functions

```python
def greet(name: str, times: int = 1) -> str:
    return (f"Hi, {name}! " * times).strip()


greet("Ada")  # -> "Hi, Ada!"
greet("Ada", times=3)  # -> "Hi, Ada! Hi, Ada! Hi, Ada!"
```

## Common pitfalls

- Mutable default arguments are shared across calls: `def f(x=[])` binds `[]`
  once. Use `None` + an inner guard instead.
- Variable scope: names assigned inside a function are local unless declared
  `global`/`nonlocal`.
- `is` checks identity (same object), `==` checks equality (value). Never use
  `is` to compare values like `1 is 1` (works for small ints by caching only).

# Python practice

## Practical task template

Each practice topic follows the loop: **understand → reproduce → extend**.

1. Pick a small, self-contained goal (e.g. "build a todo CLI").
2. Write the minimal code to pass the first milestone.
3. Add one small improvement (error handling, tests, CLI flag).
4. Refactor once, then commit.

## Exercise: reverse a string

```python
def reverse(s: str) -> str:
    return s[::-1]


assert reverse("abc") == "cba"
```

## Exercise: word counts

Count case-insensitively, stripping punctuation:

```python
import re
from collections import Counter


def word_counts(text: str) -> Counter:
    words = re.findall(r"[a-z0-9]+", text.lower())
    return Counter(words)


text = "Hello, world! Hello again."
print(word_counts(text))  # Counter({'hello': 2, 'world': 1, 'again': 1})
```

## Practice tips

- Write a failing test first (TDD); watch it fail, then implement.
- Keep functions short (< 25 lines); one responsibility per function.
- Name variables after their **role**, not their type (`names` not `list_of_names`).
- Run `python -m pytest -q` often — green is good; red is a signal, not a failure.

## Debugging

- `print()` is fine for quick checks; use `logging.debug(...)` for persistent logs.
- `python -m pdb script.py` opens the debugger at the first line.
- Use breakpoints (`breakpoint()`) to drop into `pdb` mid-execution.

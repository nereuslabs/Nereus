# Python advanced

## Object-oriented programming

```python
class Learner:
    def __init__(self, name: str) -> None:
        self.name = name
        self.skills: list[str] = []

    def add_skill(self, skill: str) -> None:
        if skill not in self.skills:
            self.skills.append(skill)

    def __repr__(self) -> str:
        return f"Learner(name={self.name!r}, skills={self.skills})"


a = Learner("Grace")
a.add_skill("Python")
print(a)  # Learner(name='Grace', skills=['Python'])
```

Key concepts:
- `__init__` — constructor; `self` binds the instance.
- `__repr__` — unambiguous string for debugging.
- Inheritance: `class AdvancedLearner(Learner):` with `super().__init__(...)`.
- `@property` for computed accessors; `@classmethod`/`@staticmethod` for
  alternative constructors.

## Iterators and generators

```python
def countdown(n: int):
    while n > 0:
        yield n  # lazy: yields one value at a time
        n -= 1


for x in countdown(3):  # 3, 2, 1
    print(x)
```

`yield` makes the function a generator: state is suspended/resumed between
calls, which is memory-efficient for large sequences.

## Decorators

```python
from functools import wraps


def log_calls(fn):
    @wraps(fn)
    def wrapper(*args, **kwargs):
        print(f"calling {fn.__name__}")
        return fn(*args, **kwargs)

    return wrapper


@log_calls
def greet(name: str) -> str:
    return f"hi {name}"


greet("ada")  # prints "calling greet", returns "hi ada"
```

## Concurrency

- `threading` — IO-bound (releases GIL on wait); shared memory.
- `asyncio` — cooperative IO concurrency (`async`/`await`); single thread.
- `multiprocessing` — CPU-bound; separate processes, bypasses GIL.
- Prefer `asyncio` for concurrency-bound I/O; reach for threads/processes
  only when the workload demands it.
